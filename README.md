# Full Git Knowledge
## git configuration
```
git config --global user.name 'username'
```
```
git config --gloabal user.email 'useremail'
```
## clone a repo (auto add git init)
```
git clone <repo-link>
```
## check staged file
```
git status
```
## add staged file
```
git add <file-name>
```
```
git add .
```
## commit file
```
git commit -m 'message'
```
## push file
```
git push origin main
```
git push -u origin main
```
